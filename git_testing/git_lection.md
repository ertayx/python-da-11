git - система контроля версий
github - платформа для храенения git репозиториев и совместной работы

git init - инициализация git системы
git add filename/dirname - добавление изменений в список для сохранения
git status - проверка состояния проекта
git commit -m 'comment' - сохранение версии (checkpoint)

git push - добавление изменнений в github
git pull - стягивание изменнений с github
git branch - просмотр текущей ветки
git branch branch_name - создание ветки
git checkout branch_name - переход к ветке
pull request/merge request - обьедениение изменнений веток
git clone - клонирование проекта
